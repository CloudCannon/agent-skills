# Troubleshooting

Symptom → cause → fix. SSG-specific rows live in the SSG's `troubleshooting.md` — [Astro](astro/troubleshooting.md), [Hugo](hugo/troubleshooting.md).

## On a Bookshop site

| Symptom                                                                                                  | Cause                                                                                                                                                            | Fix                                                                                                            |
| -------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| The editor's Add menu for a component array is empty                                                     | `@bookshop/generate` didn't run or failed, so the structures were never written; or `spec.structures` names a different key than the input's `_structures.<key>` | Check the CloudCannon build log for the postbuild step. Align the two keys                                     |
| A new component is missing from the Add menu                                                             | Its `spec.structures` doesn't list the array's structure key, or the site hasn't built on CloudCannon since it was added                                         | Add the key; build on CloudCannon — structures only exist in CloudCannon builds                                |
| Build log: "Could not find any Bookshops"                                                                | No `bookshop/bookshop.config.{js,cjs}`, or it's inside a dot-directory                                                                                           | Add the config, or pass `--dot` to `@bookshop/generate`                                                        |
| Build log: "Could not find any output sites"                                                             | `@bookshop/generate` ran without a CloudCannon build output — usually run locally                                                                                | It only runs on CloudCannon. Build locally with the SSG alone                                                  |
| Build log: "No live editing connected as no pages contained Bookshop components"                         | No built page carries Bookshop's HTML comments — components rendered outside Bookshop's calls, or comments minified away                                         | Render through the SSG's Bookshop calls; keep HTML comments in minified output — see the SSG's troubleshooting |
| Build log: "…contains old (2.0) syntax"                                                                  | A `*.bookshop.yml` still uses `props` / `component`                                                                                                              | `npx @bookshop/up@latest` rewrites them                                                                        |
| Build log: "referenced bookshop:x, but the component x does not exist"                                   | A `bookshop:` slot in a blueprint names a missing component                                                                                                      | Fix the name, or add the component                                                                             |
| Editor console: "Your Bookshop SSG plugin is running version X, but @bookshop/live is running version Y" | The Bookshop packages are on different versions                                                                                                                  | [maintaining.md § Upgrading Bookshop](maintaining.md#upgrading-bookshop)                                       |
| Editor banner: "Error Loading Bookshop Live Editing"                                                     | `/_cloudcannon/bookshop-live.js` failed to load or start                                                                                                         | Check the console and network tab for that file and its errors                                                 |
| A component doesn't update as you type, or isn't clickable                                               | Logic in the layout between front matter and the call                                                                                                            | Move the logic into the component — [bookshop.md § Live editing](bookshop.md#live-editing)                     |
| Site data is empty in live renders                                                                       | The data file has no `data_config` entry                                                                                                                         | Add it to `cloudcannon.config.yml`                                                                             |
| A component that shouldn't re-render live (nav, footer) does                                             | Live rendering is on for every top-level call by default                                                                                                         | `live_render: false` on that call                                                                              |
| Console: "Error rendering bookshop component X … expected in certain cases"                              | A render threw — often transient while a block is being added, removed or reordered                                                                              | Ignore it if it clears; otherwise debug that component                                                         |

## Partway through a migration

| Symptom                                                                   | Cause                                                                               | Fix                                                                                                                                 |
| ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| The build breaks, or blocks vanish, right after renaming `_bookshop_name` | The Bookshop dispatcher still selects on `_bookshop_name`                           | Rename, resolve and dispatch in one step — [migrating-to-editable-regions.md § Steps](migrating-to-editable-regions.md#steps)       |
| The Add menu is empty after removing the postbuild hook                   | The structures were generated, never committed                                      | [migrating-to-editable-regions.md § Writing `_structures`](migrating-to-editable-regions.md#writing-_structures-from-bookshopyml)   |
| Newly added blocks start with different values than under Bookshop        | Hand-written structures pre-fill arrays or nested slots that Bookshop started empty | Match Bookshop's rewrites — [bookshop.md § What `@bookshop/generate` does](bookshop.md#what-bookshopgenerate-does)                  |
| Components are no longer clickable in the editor                          | Bookshop's bindings are gone and no regions replaced them                           | Run the census and add regions — [cloudcannon-visual-editing](../cloudcannon-visual-editing/SKILL.md)                               |
| A text region shows an error card on a number                             | A blueprint value Bookshop rendered as a bare number                                | Quote it — [editable-regions.md § Value types per region](../cloudcannon-visual-editing/editable-regions.md#value-types-per-region) |

Once Bookshop is fully removed, region problems belong to [cloudcannon-visual-editing/troubleshooting.md](../cloudcannon-visual-editing/troubleshooting.md).
