# Troubleshooting (Hugo)

Hugo rows only. Check [../troubleshooting.md](../troubleshooting.md) first.

| Symptom                                                             | Cause                                                                                                              | Fix                                                                                                                                                         |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Build error: `📚 Error from Bookshop: Component "x" does not exist` | No `components/x/x.hugo.html` or `components/x.hugo.html` — often a shared helper called with `partial "bookshop"` | Fix the name; call helpers with `bookshop_partial`                                                                                                          |
| Build error: "bookshop_bindings expected a string"                  | The data was passed as a value                                                                                     | Wrap the expression in backticks: ``partial "bookshop_bindings" `.Params.x` ``                                                                              |
| Build error on an image inside a component directory                | The library's `config.toml` mount lacks `includeFiles = ["**/*.hugo.html"]`                                        | Add it, or run `npx @bookshop/up@latest`                                                                                                                    |
| Component lookups fail after upgrading Hugo past 0.146              | Hugo lowercases template names; older Bookshop can't find mixed-case components                                    | Upgrade Bookshop to 3.18.3 or later                                                                                                                         |
| Live editing never connects on a site built with `--minify`         | Minification strips Bookshop's HTML comments                                                                       | `minify.tdewolff.html.keepComments: true`                                                                                                                   |
| A component renders empty or errors only in the editor              | It calls `resources.Get`, `site.GetPage` or a site partial outside the library                                     | Branch on `site.Params.env_bookshop_live`, or add the partial through `extraFiles` — [bookshop.md § Live editing in Hugo](bookshop.md#live-editing-in-hugo) |
| `.Site.Data` is empty in the editor                                 | Only `site.Data` is populated live                                                                                 | Use `site.Data`, and add a `data_config` entry                                                                                                              |
| Editor console: "[hugo-engine] No component found for X"            | The name isn't in the library bundle — usually a site partial                                                      | Move it into the library, or add it to `extraFiles`                                                                                                         |
| The editor is slow or freezes while typing                          | Bookshop before 3.19 rendered Hugo on the main thread                                                              | Upgrade to 3.19 or later                                                                                                                                    |
