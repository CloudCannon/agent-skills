# Troubleshooting (Eleventy)

Eleventy rows only. Check [../troubleshooting.md](../troubleshooting.md) first.

| Symptom                                                        | Cause                                                                                           | Fix                                                                                                                                                                                  |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Page-builder blocks build but never update live in the editor  | The dynamic name has spaces inside the braces: `"{{ block._bookshop_name }}"`                   | Write `"{{block._bookshop_name}}"` — [bookshop.md § Live editing in Eleventy](bookshop.md#live-editing-in-eleventy)                                                                  |
| A component renders empty or errors only in the editor         | It uses a filter, shortcode or tag from the Eleventy config, which the live engine doesn't have | Branch on `env_bookshop_live`, or move the logic into the component — [bookshop.md § Live editing in Eleventy](bookshop.md#live-editing-in-eleventy)                                 |
| Build error after a tag rewrite: unknown tag `includeWith`     | The editable-regions plugin isn't added yet                                                     | [migrating-to-editable-regions.md § Install the plugin before the rewrite](migrating-to-editable-regions.md#install-the-plugin-before-the-rewrite)                                   |
| The Add modal is empty after moving structures into files      | The files are loaded with `_structures_from_glob`                                               | Use `values_from_glob` — [migrating-to-editable-regions.md § Structure files](migrating-to-editable-regions.md#structure-files)                                                      |
| A migrated component shows raw markdown in the editor          | The site's markdown filter is named `renderContent`, which the plugin reserves                  | Rename it — [cloudcannon-visual-editing/eleventy/visual-editing-reference.md § Reserved names](../../cloudcannon-visual-editing/eleventy/visual-editing-reference.md#reserved-names) |
| `sass` fails, or compiles differently, after removing Bookshop | `sass` came only through `@bookshop/sass`                                                       | Add `sass` as a dev dependency — [migrating-to-editable-regions.md § Component styles](migrating-to-editable-regions.md#component-styles)                                            |
